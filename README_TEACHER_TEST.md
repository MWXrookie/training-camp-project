# Recall AI 错题本老师测试包说明

版本日期：2026-08-10

## 这是什么

这是 Recall AI 错题本的三天受控试用版本地 Web 应用。

测试目标不是判断 UI 好不好看，而是观察一位老师能否理解并完成核心链路：

```text
进入应用 -> 上传错题 -> 框选目标题目 -> AI 生成待确认草稿 -> 修改确认 -> 入库 -> 写便签 -> 复习
```

## 测试边界

- 只用于小范围受控测试，不是公开产品。
- 请只上传脱敏题图。
- 不要上传学生真实姓名、学校、班级、联系方式、头像或其他可识别信息。
- 不要上传真实未成年人隐私图片。
- 图片会临时发送给千问视觉模型做分析。
- 应用服务端不保存原图；浏览器只保存确认后的错题、便签和复习记录。

## 运行前准备

电脑需要安装 Node.js。

检查方式：

```powershell
node -v
```

如果能看到版本号，就可以继续。

## 配置千问 Key

如果要测试真实 AI 分析，需要在项目根目录新建 `.env.local`。

可以复制 `.env.example`，然后把 `DASHSCOPE_API_KEY` 改成自己的阿里云百炼/千问 Key：

```env
DASHSCOPE_API_KEY=你的_key
QWEN_MODEL=qwen-vl-plus
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

不要把 `.env.local` 发给别人。

如果没有 Key，也可以测试文字录入、错题库、便签、复习和清空数据，但图片 AI 分析会失败。

## 启动方式

在项目根目录打开 PowerShell，运行：

```powershell
$env:PORT='4174'
node .\server.mjs
```

看到服务启动后，浏览器打开：

```text
http://localhost:4174/
```

试用口令：

```text
recall
```

也可以右键 `START_LOCAL_TEST.ps1`，选择“使用 PowerShell 运行”。

## 建议测试任务

1. 输入口令 `recall` 进入应用。
2. 上传一张脱敏的整页题图。
3. 在裁剪界面拖动选框，只框住一道目标题。
4. 点击“分析选中区域”。
5. 等 AI 返回待确认草稿。
6. 至少修改一个字段，比如题干、答案或便签。
7. 点击“确认入库并加入复习”。
8. 进入详情页，补一句自己的解题理解。
9. 开始复习，提交一次自评。
10. 在“我的”页面尝试导出或清空本机数据。

## 反馈重点

请记录这些问题：

- 是否一眼能找到“上传错题”？
- 裁剪选题是否顺手？
- 是否理解“AI 草稿确认前不会入库”？
- 老师是否愿意让学生写自己的便签？
- 复习页是否知道下一步该做什么？
- AI 返回内容有哪些明显错误？
- 哪一步最容易卡住？
