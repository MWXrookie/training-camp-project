## 2. 试用边界确认

- [ ] 测试者均为已知情成年人。
- [ ] 未上传真实姓名、学校、联系方式、未成年人隐私或敏感图片。
- [ ] 测试前已说明当前版本是本地受控试用，不是公开产品。
- [ ] 测试前已说明当前版本使用千问视觉模型处理上传图片。
- [ ] 测试者知道上传分析后仍需确认，确认前不会入库。
- [ ] 测试者知道本机数据可导出和清空。

## 3. 测试任务脚本

每位测试者按以下顺序完成，观察者不要代操作。

| 序号 | 任务 | 通过标准 | 观察记录 |
|---:|---|---|---|
| 1 | 进入应用，阅读告知，输入口令 `recall` | 能进入首页，理解受控试用边界 |  |
| 2 | 找到上传错题入口，上传脱敏数学错题图片或用文字录入题干 | 不经提示能找到入口，并知道图片和文字都会先生成草稿 |  |
| 3 | 查看待确认草稿，对照原图修改至少一个字段 | 能说出“确认前还没入库” |  |
| 4 | 确认入库，并进入错题库查看详情 | 草稿进入已确认错题库 |  |
| 5 | 在详情页写一句自己的解题便签并保存 | 看到保存反馈，再打开仍存在 |  |
| 6 | 从详情或复习页完成一次复习 | 有作答、自评、下次复习时间和复习记录 |  |
| 7 | 在复习后补一句便签 | 能找到便签入口，愿意写自己的理解 |  |
| 8 | 尝试导出 JSON 或清空本机数据 | 理解数据只在本机，操作可完成 |  |
| 9 | 用自己的话说明产品和拍照搜答案的区别 | 能说出“错题复习/确认/便签/复习”中的至少两点 |  |

## 7. 发布阻断项检查

- [ ] 未确认草稿没有进入正式错题库。
- [ ] 复习提交不会重复生成记录。
- [ ] 清空后数据不会自动恢复。
- [ ] 失败态不要求用户刷新页面才能继续。
- [ ] 移动端主按钮没有被遮挡。
- [ ] 页面没有暗示已经接入真实 AI。
- [ ] 上传分析前有受控试用告知。
- [ ] 模型 Key 没有出现在浏览器代码、日志或导出数据中。
