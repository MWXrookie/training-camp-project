### T1-05B 千问视觉超时轻量兜底（Done）

目标：真实题图不应因为模型偶发响应慢而直接显示无法分析。  
允许修改：`server.mjs`、`web/trial-api-contract.test.mjs`、`.env.example`、`docs/API_SPEC.md`、`docs/PROJECT_STATE.md`、`docs/TRIAL_TASK_ALLOCATION.md`、`docs/ERROR_LOG.md`。  
验收：

- 标准视觉分析请求有可配置超时，默认 75 秒；
- 标准请求限制输出长度，避免长解析拖慢草稿生成；
- 超时后自动使用轻量草稿 prompt 重试一次；
- 轻量模式允许答案和完整解析为空，但必须尽量返回可核对题干；
- 同一真实题图直连 `/api/trial/analyze` 可以返回合法 `data`；
- API 契约测试覆盖轻量 prompt。

结果：已完成。用户此前反馈无法识别的图片直连复测返回 `200` 和待确认草稿。
